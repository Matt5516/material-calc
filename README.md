# BagOrBulk

Free concrete, gravel, mulch, topsoil and cubic yard calculators that tell you how much to buy and whether bags or a bulk delivery costs less.

Live: https://bagorbulk.com/

Static HTML/CSS/JS, no backend, no ads, no trackers. Math lives in `assets/calc.js` (tested). Pages are generated by the shared build in Matt's sites workspace, so don't edit the HTML by hand.
